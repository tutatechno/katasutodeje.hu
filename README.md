# katasutodeje.hu

Kata Sütődéje – mindenmentes sütemények honlapja.

- `index.html`, `styles.css`, `script.js` – az oldal
- `termekek.js` – termékek, árak (itt kell szerkeszteni)
- `rendeles.php` – rendelés e-mailben (csak PHP-s tárhelyen működik; GitHub Pages-en a rendelés a látogató levelezőprogramján keresztül megy el)
- `img/` – fotók
